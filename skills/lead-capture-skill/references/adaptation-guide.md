# Industry Adaptation Guide

Use this to define genuine-inquiry signals and form fields per client industry.
Add a new entry below whenever a new industry is onboarded.

---

## Wedding Venue (reference example)

**Genuine inquiry signals:**
- Direct keywords: "wedding," "book a tour," "availability," "pricing," "venue"
- Indirect but clear intent: caller inquiring on behalf of someone else (e.g. a
  parent looking for their child)
- Any mention of an event, date, or guest count

**Non-genuine signals:**
- Sales/spam calls (warranties, insurance, robocalls)
- Wrong number with no venue-related context
- Unrelated vendor solicitations

**Form fields (the venue client's actual form):**
- Full Name*
- Phone Number*
- Email Address*
- Event type* (Wedding Ceremony / Ceremony + Reception / Reception Only /
  Elopement / Other)
- Preferred event date*
- Estimated guest count
- Budget range
- Services interested in (venue only, ceremonial setup, reception setup,
  tables & chairs, coordination, décor, not sure yet)
- Vision/style notes (open text)
- Wants a tour? (Yes / No / Maybe later)
- How they heard about the venue
