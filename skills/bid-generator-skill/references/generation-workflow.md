# Generation Workflow (Per New Bid)

Run this once a client business's style/template profile exists
(`style-extraction-guide.md`).

## 1. Minimum required intake before drafting

Do not attempt to draft a bid until at least the following are provided.
Do not fill gaps by guessing or by copying from a past job — an empty
field should stay empty and be flagged back to the contractor, not
invented.

- Client name (and job site address, if the template includes it)
- Scope of work (what's actually being done)
- Pricing (itemized or lump sum, matching however the profile presents it)
- Timeline / estimated duration or start date
- Materials, if the contractor's template calls them out separately from
  scope

This list is a starting floor, not exhaustive — cross-check against what
fields the specific client's template actually contains (from
`style-extraction-guide.md` §1) and require whatever that template needs.

## 2. Pull reference material

- The client's style/template profile (voice + literal layout)
- The 3-5 most recent, most relevant before/after pairs, per
  `versioning-approach.md`

## 3. Draft

Reproduce the template exactly — layout, headers, formatting, branding —
and populate only the content fields from step 1. Voice and phrasing
should match the profile and lean on the before/after examples where
relevant; facts must come only from what was provided in step 1.

## 4. Apply guardrails

- Insert the review-checkpoint note (`review-checkpoint.md`)
- Flag any legal/warranty/liability sections per `legal-guardrail.md` —
  carried over verbatim, marked for confirmation, never rewritten

## 5. Hand off

Deliver the finished document in whatever format matches the client's
actual template (Word, PDF, Canva — see Open Research Item #2 in
SKILL.md). The contractor reviews, revises if needed, and sends. If they
revise, the sent version should be captured as the "after" half of a
before/after pair per `versioning-approach.md`.
